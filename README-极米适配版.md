# Aerial 极米适配版（1.57-xgimi）

基于官方 [pengchujin/aerial-tv](https://github.com/pengchujin/aerial-tv) **v1.57** 适配而来。
其他电视使用与官方版本无异，已融合官方版本，只是功能增加了不少，放心使用。

## 本次更新

- **更新至官方 v1.57 版本**
- 该版本适配了 HDMI 的信号源壁纸，选择后会将 HDMI 的画面当成壁纸，且任何操作都不会停止，切换其他壁纸后停用，进入屏保后也会停止，但是等待 3 秒后会再次开启
- 「HDMI」作壁纸时：第一排下沉露出 50%，焦点磁贴升起 90%、其余保持 50%；大字名称居中跟随焦点磁贴上方，保持和动态壁纸设置一致
- 个性化「我的视频」声音条下新增**「磁贴下沉 是/否」**开关（选「否」则与航拍壁纸一样正常显示）
- **屏保与壁纸之间切换优化**，如果是相同类型的壁纸与屏保，切换时候不会停止壁纸播放，同样的屏保返回壁纸也不会暂停壁纸，优化了磁贴显隐特效，现在看起来非常丝滑
- **视频屏保铺满**：以前按影片比例留边、比桌面上的同一部片小一圈，现在和桌面壁纸一样满屏裁切
- 我的视频**尺寸固定 720p**：以前 3.5 秒没出帧就退回影片自己的尺寸，播放器要重来一次，回桌面会「缩一下」；现在说定 720p，桌面和屏保用同一个尺寸，画面一格都不动
- **回桌面不再缩放**：只有真的换过播放器才等一秒；桌面还在屏上（打开更多磁贴、开面板）只让解码器歇着，画面原地不动，不取停帧也不淡出
- **屏保左下角可以加文字**：手机端「我的视频」里新增一个输入框，填的字显示在「我的视频」屏保左下角，字体和位置与航拍地名一样；留空不显示
- **「第一排底板」改成三选一**：动态壁纸下显示 / 静态壁纸下显示 / 不显示（原来只有「玻璃 / 不显示」），老设置自动沿用
- **打开更多磁贴时上方不再压黑**：去掉了那条 120dp 黑渐变
- 更改了更新来源，不再提示官方的版本更新
- 其他一些优化自行体验

### 安装

- 覆盖安装需与已装版本同签名；若电视已装官方版请先卸载再装
- 极米桌面建议 `pm disable-user com.xgimi.home`，让 Aerial 成为唯一 HOME
- 包名 `app.orchard.tv`，versionName `1.57-xgimi`，versionCode `71`

**本机测试设备为极米 Z7X 高亮版，真机测试有效**
