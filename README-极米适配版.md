# Aerial 极米适配版（1.57-xgimi）

基于官方 [pengchujin/aerial-tv](https://github.com/pengchujin/aerial-tv) **v1.57** 适配而来。
其他电视使用与官方版本无异，已融合官方版本，只是功能增加了不少，放心使用。

## 本次更新

- **更新至官方 v1.57 版本**
- 该版本适配了 HDMI 的信号源壁纸，选择后会将 HDMI 的画面当成壁纸，且任何操作都不会停止，切换其他壁纸后停用，进入屏保后也会停止，但是等待 3 秒后会再次开启
- 「HDMI」作壁纸时：第一排下沉露出 50%，焦点磁贴升起 90%、其余保持 50%；大字名称居中跟随焦点磁贴上方，保持和动态壁纸设置一致
- 个性化「我的视频」声音条下新增**「磁贴下沉 是/否」**开关（选「否」则与航拍壁纸一样正常显示）
- 更改了更新来源，不再提示官方的版本更新
- 其他一些优化

## 这个版本做了什么

在官方版本之上，针对极米投影仪做了这些增强（上游自带功能全部保留）：

### 控制中心

- **Wi-Fi 名称**能正常显示当前连接的名称
- **亮度条**能正常改变投影仪亮度
- **信号源**可正常切换，包括主屏幕的磁贴
- **无线按钮**正常打开
- **设置按钮**正常打开
- 新增一个**随机一张**的按钮：点一下从必应归档取一张老图设为壁纸，只留一张、不占存储

### 个性化

- 新增**随机一张**的卡片：点一下从必应归档取一张老图设为壁纸，只留一张、不占存储
- 新增**第一排显示大字**，可在个性化里开启
- 屏保选择「系统内置」时打开极米内置屏保
- **动态壁纸**：手机端扫码上传视频作为壁纸，与「我的视频」共用声音、音量、磁贴下沉等设置
- **信号源壁纸**：把 HDMI 画面当壁纸用，全屏铺满、声音直通电视喇叭
- **手机端扫码即连**：地址带令牌，只有电视上扫得到

### 安装

- 覆盖安装需与已装版本同签名；若电视已装官方版请先卸载再装
- 极米桌面建议 `pm disable-user com.xgimi.home`，让 Aerial 成为唯一 HOME
- 包名 `app.orchard.tv`，versionName `1.57-xgimi`，versionCode `71`

## 构建

```bash
# local.properties
sdk.dir=C\:\\Users\\Administrator\\android-sdk

# 构建
JAVA_HOME=C:/Users/Administrator/jdk-17.0.20.1+1 \
  gradle --offline assembleStandardRelease
```

调试签名 SHA-256 `5cae…7964`，与电视上已装版本一致，覆盖安装不会清除数据。

**本机测试设备为极米 Z7X 高亮版，真机测试有效**
